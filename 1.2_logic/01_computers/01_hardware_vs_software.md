# Part 1 – Hardware vs Software
## Explain Hardware
Hardware is the physical part of a computer that you can see and touch.
Write **at least 50 words** explaining what hardware is.
Hardware is the physical part of a computer that you can see and touch. For example Macbook has hardware components such as the keyboard , screen, processors , RAM, battery and stoarage drive.

## Explain Software
software is a set of programs, instructions, and data that tells a computer what to do.
Write **at least 50 words** explaining what software is.
Software is a set of programs, instructions, and data that tells a computer what to do. For example MacOs, windows, Google chrome, Microsoft Word, and Python are software

## How Do Hardware and Software Interact?
Hardware and software interact through instructions and data. Software provides instructions, while hardware executes them to perform tasks.
Write **at least 50 words** describing how they interact.
Hardware and software interact to make a computer function properly. Software provides instructions that tell the hardware what tasks to perform.The CPU processes these instructions, while RAM temporarily stores data during processing. Input devices, such as keyboards and mice, allow users to enter information, and the Output devices, such as monitors and speakers, display the results. The operating system manages communication between hardware and software, allowing the computer to perform tasks efficiently.
